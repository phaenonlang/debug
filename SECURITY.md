# Security policy

## Supported versions

The latest minor release is supported: a security fix ships as a patch release of it, and older
minor lines get none. Until 1.0, `phaenon/runtime` is released in lockstep with the compiler,
`phaenon/phn`, so a project on the latest compiler is on the supported line.

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting: **Report a
vulnerability** in this repository's **Security** tab, or
<https://github.com/phaenonlang/runtime/security/advisories/new>. Do not open a public issue or
pull request for it.

A report helps most with the affected version, the PHP version, and the smallest code that shows
the problem.
