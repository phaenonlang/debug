# Security policy

## Supported versions

The latest minor release is supported: a security fix ships as a patch release of it, and older
minor lines get none. The package reads line-map format v1, which every release of the compiler,
`phaenon/phn`, writes, so the latest `phaenon/debug` serves a project on any compiler release.

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting: **Report a
vulnerability** in this repository's **Security** tab, or
<https://github.com/phaenonlang/debug/security/advisories/new>. Do not open a public issue or
pull request for it.

A report helps most with the affected version, the PHP version, and the smallest code that shows
the problem.
